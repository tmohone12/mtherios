Date: 2026-09-23. Scope: isolated `E:\DEV\Projects\MythEngine` checkout and its disposable game. Server images, covers and assets remain open.

The GM's `generateNames` tool now accepts 1–12 character, place or organization names, an optional fantasy/science-fiction/horror/noir genre, style, up to four cultural blends and up to 20 exclusions. The server owns project/game scope and checks the existing GM Names setting before reserving a call. It reuses the configured narrative provider with bounded campaign context and asks for a JSON names array. The result must have the requested count, distinct 2–80-character names, no controls and no excluded names. A failed provider request or invalid result yields an `unavailable` tool observation. Candidates are stored in the existing run tool ledger and do not create canon. Successful provider usage is recorded with the run.
