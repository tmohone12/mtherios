- [sourceFiles.ts](../src/lib/server/engine/sourceFiles.ts) exposes logical authored/canonical sources and explicitly registered local folders through shared list/search/read tools. Text, Markdown and JSON support bounded listing/search, exact line ranges, hashes, revisions and continuations. Runtime folders, credentials, absolute/UNC/alternate-stream/traversal paths and link escapes are denied; open handles are checked against authorized identities.
- Request context refresh uses current canonical revisions. Compaction replaces older completed tool bodies with source handles only in the model view; raw history remains in PostgreSQL. Recent/unresolved pairs and human corrections survive. Exact wire budgeting includes tool schemas/framing/output allowance. Interactive embeddings, actor decisions, classification, dialogue and image requests share the durable reservation ledger.
- GM public narration/source inspection receives eligible public/player-known evidence and action receipts. Private working history and provider continuation bodies stay out of public activity. Source opening revalidates the original run range, server scope, revision and hash.
- Story and Assistant panels show persisted activity, request/context counts, known/unknown usage, stop reasons, questions, source ranges and resume/cancel controls. GM SSE reconnects from a persisted cursor; snapshots recover state after reload. Agent Tools exposes runtime rollback flags and selected read-only source folders.

Defaults: eight provider dispatches, sixteen tools, 120,000 accounted/reserved tokens and 120 seconds of active time. Query embeddings and specialist requests count. Service `metadata.agentBudget` can set explicit overrides and optional monetary reservations; unknown prices are refused when a monetary cap lacks a conservative reservation. Background indexing/jobs retain their distinct owners.
