## Implemented slices

- The GM planner's `askJev` result carries an immediate-response purpose, actor/action/evidence fingerprints, configured and returned model IDs, candidate descriptions, selected option, source IDs, optional selected memory, and usage. The turn reuses only a matching validated result and sends the selected intention to that speaker's dialogue prompt. Other actors retain the automatic decision path. One Jev request can select an option and a bounded memory.
- Actor briefs include bio, background, appearance, persona, goals, and isolated beliefs. Off-scene NPC work favors actors touched by recent sourced events, uses the isolated actor view, and can pursue an existing saved opportunity. Existing canonical writers and job idempotency remain the effect boundary.
- Director card presentation now chooses at most one sourced, action-relevant, local/actor-linked cue. Numeric pressure cannot force a remote cue into a quiet scene. Remote plot threads no longer appear in the open plot ledger. A location/branch/scene key survives checkpoint refresh and present-NPC changes, suppressing repeated optional cues; final narration feedback tracks selected, surfaced, and not surfaced separately from world-event realization.
- Dialogue coverage has a visible optional “Important exchanges” setting in AI Services. The saved server metadata controls it. The default remains “All eligible NPC speech”; important mode skips only clear routine greetings, retains uncertain or substantive exchanges, and preserves skipped lines verbatim.
- Removed the unreferenced browser `StrategicWorldBrainService` wrapper. The server Director remains active.
- A failed or empty GM Research result no longer suppresses the later Active Recall fallback; only a source-linked answered result does. The selected faction-cue prompt no longer carries dormant plot titles or antagonist dossiers beside the local cue. The browser-only prompt no longer inserts Director cards, urgency-ranked faction actions, World Simulation plot injections/seeds/tension, or its next-beat advisory without a scene selector. It keeps established recent events, agreements, rumors, and seasonal context.
- The agent GM planner can now use a Research-gated `recall` tool for bounded private transcript, campaign page, canonical-record, actor-brief, timeline, and wiki reads. It uses the existing engine commands and shares the Active Recall argument limits. The result reaches the next planner round and narrator context, but the player-visible `tool.completed` event carries only status. A successful planner recall suppresses the later Active Recall pass for that agent turn; an unavailable result leaves the fallback available. Direct CLI and SSE turns still retain Active Recall.
- On explicit historical lookback, the shared turn path now reads a bounded canonical transcript neighborhood when prepared memory names a transcript position. This gives direct CLI/SSE turns the surrounding exchange without another model planner call; parallel POV does not receive that cross-POV read. It is an incremental direct-route migration, not yet full Active Recall replacement.
- When an explicit lookback has no prepared hit and the turn's bounded `memory.retrieve` finds a transcript position, the shared GM exploration loop now performs one deterministic `campaign.entriesAround` follow-up. It uses the existing command runner, activity/abort handling, and at most one additional tool slot; Research-off leaves the previous deterministic behavior unchanged. The returned source IDs and excerpt enter the narrator observation packet. This covers a second direct-route case without a separate model planner request.
- With GM Research enabled, an explicit named lore/knowledge inquiry can now search canonical world records without semantic embeddings and read the first exact result through `world.record.get`, within the same three-call ceiling used for direct evidence follow-up. A world search runs only for a named world entity/faction or a knowledge inquiry with no prepared memory or wiki pages. Research-off adds no canonical search; parallel POV keeps its isolated actor path. The result is still evidence for narration, not a canonical write.
- Explicitly named lore pages now use the source path from prepared wiki context for one bounded `wiki.page` read. If the prepared context was unavailable, a `wiki.context` tool result can supply a matching page path for one follow-up read. Generic lore queries keep the compact context and do not expand every page. Both reads respect GM Research and parallel-POV boundaries.
- A direct GM Research turn can now read an explicitly named campaign Markdown path through `campaign.page.read`. The existing command validates the page kind/path and enforces indexed raw-turn evidence. The selector does not guess a file from vague prose or read an arbitrary path outside the campaign directories; Research-off and parallel POV do not add this read.
- The former Active Recall planner now uses the configured GameMaster model as an optional adaptive GM Research step. Exact sourced reads finish without that extra model pass. The visible Agent tool preference inherits a saved legacy Active Recall opt-in until a project or game override is set; an explicit off choice wins. The retired service is absent from the active browser service and prompt lists, and sync skips it while keeping saved rows and old receipts readable.
- The browser fallback turn no longer calls World Simulation for per-turn plot momentum or exposes a refresh tool for it. The generated value had no active narrator consumer after the earlier faction-pressure isolation; the stale final instruction was removed too. Browser chapter closure now creates the chapter without a speculative world event, faction move, or rumor. The World drawer routes bound stories to the existing backend tick; a local-only story shows that terminal sync is required.
- The agent planner can still inspect `campaign.status` and `plot.thread.board`, but its raw `read` observations no longer enter narrator specialist context. Scene and Director facts reach narration through the selected, budgeted packet. Other tool results, including sourced research and accepted interactions, remain available to the narrator.
- Narrator faction cards now rank by scene/action relevance without numeric pressure. A remote faction cannot enter solely because a generic player word matches a goal or resource. Numeric pressure is omitted from narrator canon, and active faction projects enter only when the player names or addresses that faction. Local identity, territory, and public background remain available for ordinary scenes.
- Scheduled future events now reach narrator context only when the player explicitly asks about a matching event or the selected scene cue names that event. Due and committed events retain their existing path. The underlying GM timeline and world schedule are unchanged; a quiet turn no longer gets a distant future move merely because it is on the calendar.
