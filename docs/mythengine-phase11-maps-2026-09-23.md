# Phase 11 map implementation evidence — 2026-09-23

Status: a canonical location-map slice is implemented and live-tested in the isolated MythEngine checkout. Phase 11 remains open until the remaining gates below are exercised.

The map document is owned by an active game location and has an independent optimistic revision. The bounded contract allows normalized region polygons, pins, tokens, layers, visibility, optional same-game links, and one public game image as background. The save path verifies active link targets, rejects public objects pointing to hidden entities, writes a retained snapshot, increments the game version and queues vault synchronization without changing containment or current player location. Restore creates a new revision. The visible World Explorer editor and GM `map` tool use the same service. Game exports include map rows, history, and referenced image bytes; imports validate and remap location/entity and asset references.
